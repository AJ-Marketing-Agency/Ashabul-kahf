# AK Website — GitHub Pages (Flat Files)

All website files are in this single folder; there are no subfolders.

## Publish
1. Open your GitHub repository.
2. Upload every file in this folder directly to the repository root, including `index.html` and `.nojekyll`.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

Keep all files together in the repository root. Asset filenames include their former folder names to avoid collisions.
